## Everything pix brings together

Hot-swap agents. Context stays warm. 01 **CODEX** starts 02 **CLAUDE** continues 03 **PI** ships

1. **One workflow for every coding agent.**Start and continue sessions across supported agents without learning a different interface for each one.
2. **Capability-honest by design.**Pix shows only the controls an agent genuinely supports, so every action has a clear contract.
3. **Your existing history, together.**Bring native agent sessions into one project timeline instead of rebuilding context from scratch.
4. **Browse history without waking an agent.**Open and inspect past sessions instantly; Pix attaches the runtime only when you send.
5. **Hand work to another agent.**Continue a session with a different agent while preserving the relevant conversation and project context.
6. **Reference any session with #.**Pull another session into the conversation for handoffs, comparisons, or focused side investigations.
7. **Fork from the moment that matters.**Branch from any completed turn without changing the original conversation.
8. **See work agents create on your behalf.**Agent-launched Pix sessions appear as visible, linked work instead of disappearing into hidden sub-processes.

1. **Run sessions and background jobs in parallel.**Keep independent work moving while Pix surfaces live jobs, progress, elapsed time, usage, and supported Stop controls.
2. **Steer now, queue next, and answer in context.**Guide a running turn, follow up afterward, and respond to structured agent questions without breaking flow.
3. **Watch the plan become progress.**Follow structured plans and todos as the agent works.
4. **Recover—or stop—with intent.**Reconnect, retry, resume, cancel, or stop using the strongest action the active agent supports.
5. **Choose the right model for the work.**Configure model, reasoning, context, and speed through one capability-aware control.
6. **Keep commands, skills, and MCP tools one search away.**Find Pix actions, agent-native commands, project skills, and connected tool servers from the same workspace.
7. **Bring rich context to every agent.**Attach images, video, and files, then reference the exact project file or folder with @ across clients.
8. **Use agent-built visualizations in the conversation.**Explore diagrams, tools, and other extension surfaces directly where the work happens.
