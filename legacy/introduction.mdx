Pix is a native and web application that brings every major coding agent into a single, coherent workspace. Before Pix, working with multiple AI coding agents meant maintaining separate terminal sessions, re-explaining your project in each tool, and losing the thread of your work every time you switched. Pix eliminates that friction by keeping your context warm across agents, persisting full session history, and letting you move between Claude Code, Codex, Cursor, and Pi as fluidly as switching tabs.

## Why Pix exists

Modern software teams rarely settle on a single coding agent. Different agents excel at different tasks — one may be faster for boilerplate generation, another more accurate for complex refactors, and a third better integrated with a particular language server. The cost of that flexibility has always been context loss and tooling sprawl. Pix was built specifically to remove that cost.

When you hot-swap agents in Pix, the session context travels with you. When you kick off a background job, it runs without blocking your active session. When you need to revisit something from last Tuesday, you search history without waking any agent. Every capability is designed around the same principle: your workflow should shape the tool, not the other way around.

## Supported platforms

Pix is designed to follow you across every device and environment you work in:

- **Mac** — The Mac app bundles both the Pix server and client. Apple Silicon is fully supported with a signed and notarized `.dmg`.
- **iPhone** — A full-featured iOS client available via TestFlight, optimised for on-the-go session management.
- **iPad** — The same TestFlight build delivers a desktop-class layout on iPad, making it comfortable for longer work sessions.
- **Web browser** — Access any running Pix server from a browser without installing anything extra.
- **Linux** — Native packages available for Ubuntu/Debian, Fedora/RHEL, and Arch-based distributions on both x64 and ARM64.

### Remote access

Connect to your Pix server from any of the above clients over your local network (LAN) or through [Tailscale](https://tailscale.com) for secure remote access from anywhere.

## Additional capabilities

Beyond agent management, Pix provides a set of power features you can layer in as your workflow grows:

- **File and image attachments** — Use `@` to attach files or images directly in a session message.
- **Session cross-references** — Use `#` to reference another session inline, giving agents full context from past conversations.
- **MCP tool servers** — Connect any Model Context Protocol server to extend what your agents can do.
- **Agent handoffs** — Transfer work from one agent to another, optionally forking from a specific turn in the conversation.
