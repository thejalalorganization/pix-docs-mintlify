This guide walks you through everything you need to go from a fresh Pix install to an active coding session. By the end, you'll have a coding agent connected, a project set up, and your first message on its way — with live progress streaming back to you in real time.

<Steps>
  <Step title="Open Pix">
    Launch the Pix app on your Mac or, if you're on another device, navigate to your Pix server's address in a web browser (for example, `http://192.168.x.x` over LAN, or your Tailscale address remotely).

    The first time you open Pix you'll land on the home screen. From here you can see recent sessions, navigate to settings, and create new projects.
  </Step>

  <Step title="Connect an agent">
    1. Click the **Settings** icon (gear) in the sidebar.
    2. Open the **Agents** section.
    3. Select an agent from the list — **Claude Code**, **Codex**, **Cursor**, or **Pi** — and follow the prompts to authenticate or point Pix to the agent's binary.
    4. Once connected, the agent appears in your agent switcher with a green indicator.

    Pix automatically surfaces capability-aware controls for each agent, so you only see options and toggles that the connected agent actually supports. You can connect multiple agents and switch between them at any time.

    <Tip>
      If you're unsure which agent to start with, Claude Code is a good default for general-purpose coding tasks. You can always add more agents later.
    </Tip>
  </Step>

  <Step title="Create a project">
    1. Click **New Project** on the home screen.
    2. Give your project a name.
    3. Link it to a local repository by clicking **Browse** and selecting the folder, or choose **Scratch Workspace** to start without a repository.
    4. Click **Create**.

    Projects keep your sessions organised and give agents a stable working directory to read from and write to.
  </Step>

  <Step title="Start a session">
    1. Open your new project and click **New Session**.
    2. Select the agent you connected in Step 2 from the agent picker at the top of the session.
    3. Type your first message — a task description, a question, or a code snippet — and press **Send** (or **Return**).

    Pix streams the agent's live progress directly in the session view. You can see token usage, tool calls, and file changes as they happen. If the agent goes in an unexpected direction, click **Steer** to send a follow-up message mid-run, or click **Stop** to halt execution cleanly.
  </Step>
</Steps>

<Tip>
  Use `#session-name` anywhere in a message to reference a past session — the agent receives the full context from that session inline. Use `@filename` or `@image` to attach files and images from your project directly in the message box.
</Tip>
