Keyboard shortcuts let you move through Pix at full speed. Whether you're jumping between sessions, sending a message to an agent, or pulling up a workspace-wide search, every action in this reference has a key sequence that keeps your hands on the keyboard. Learn the ones that match your workflow first — ⌘K and ⌘N alone will cover most of what you do every day.

<Note>
  Shortcuts may vary by platform (Mac, iPad, web) and by the active agent. The shortcuts listed here reflect the Mac client. Some shortcuts may not be available on all platforms or for all agent types.
</Note>

---

## Navigation

| Shortcut | Action |
|---|---|
| `⌘N` | Start a new session |
| `⌘P` | Switch project |
| `⌘W` | Close the current session |
| `⌘⇧F` | Search across all sessions |

---

## Composer

Use these shortcuts while the composer (message input) is focused.

| Shortcut | Action |
|---|---|
| `#` | Reference another session — opens the session picker inline |
| `@` | Reference a file or folder — opens the file picker inline |
| `⌘↩` or `⇧↩` | Send the current message |
| `Esc` | Cancel or dismiss the current composer action (e.g. close an inline picker) |

---

## Workspace

| Shortcut | Action |
|---|---|
| `⌘K` | Open unified search — find Pix actions, slash commands, and MCP tools in one place |

---

## Agent Controls

| Shortcut | Action |
|---|---|
| `Esc` | Stop the current agent run (where supported by the active agent) |

<Note>
  The stop/cancel behavior of `Esc` depends on the active agent. Some agents support graceful interruption; others complete the current step before stopping. Check the agent's documentation for details.
</Note>

## Tips

<CardGroup cols={2}>
  <Card title="⌘K for Everything" icon="magnifying-glass">
    When in doubt, press `⌘K`. The unified search surfaces Pix actions, agent commands, and MCP tools in a single palette — you rarely need to reach for the mouse.
  </Card>
  <Card title="# and @ in the Composer" icon="at-sign">
    Type `#` to pull in context from a previous session, or `@` to ground the agent in a specific file or folder. Both work mid-sentence — you don't have to be at the start of a line.
  </Card>
</CardGroup>
